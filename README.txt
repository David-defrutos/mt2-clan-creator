MT2 CLAN CREATOR - WINDOWS

1. Extract the entire ZIP folder to a location where you can save files.
2. Double-click Launch-Creator.cmd. The creator opens in your browser.
3. Choose Create my first clan for a short guided start, or Create my clan to start from scratch.
4. Changes are saved automatically. Save and exit lets you continue later.

Node is included. You do not need to install it or run terminal commands.

To compile a clan, you need Monster Train 2 and the .NET SDK 10 or newer.
To play it, install BepInExPack, Trainworks Reloaded and Conductor in your mod manager profile. The final wizard page explains each step.

UPDATING OR MOVING TO ANOTHER COMPUTER

Open Backups and updates on the home page, select your clan and choose Save backup. Keep the downloaded .mt2draft file somewhere safe. It includes your draft and uploaded images.
Extract the new creator into a separate folder, open it, and choose Restore a backup. Your restored clan is a new independent draft. Existing clans are not replaced. Repeat for each draft you want to keep.
You can also keep a separate copy of your whole data folder. Never extract an update over your existing data folder.

The first-clan route contains prepared examples. You can change any of them, review paths under All clan steps, and switch to the full wizard at any time.
Preview path and level selectors affect only the preview. The attack, health and capacity fields remain base values. Enlarge card opens the full card for reading.
